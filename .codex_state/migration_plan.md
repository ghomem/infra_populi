resource_type / title / required_base are STRUCTURAL classification facts consumed live by the harness via gen_migration_order.py --classify. title for defines is a default test title and may be overridden. Parameter VALUES live in untracked params JSON, not here.

internal_deps is an ENVIRONMENT-SPECIFIC PROJECTION: it lists dependencies as they apply on the Ubuntu test node, because the topological sort in gen_migration_order.py reads it as unconditional. Dependencies that only apply on another OS are deliberately OMITTED from internal_deps and preserved in the prose depends_on column instead. Examples: packages_base includes extra_packages_el only on RedHat (packages_base.pp line 29), so extra_packages_el is absent from its internal_deps; node_base includes filesystem_yum on RedHat and filesystem_apt + filesystem_lib64 otherwise (node_base.pp line 110), so internal_deps lists the Ubuntu branch only. The prose depends_on column carries the full cross-environment truth. KNOWN LIMITATION: if a RHEL test node is ever added, internal_deps must be revisited for that environment; a conditional-annotation schema (e.g. dep[RedHat]) is the natural path but is deliberately not built until something reads it.
