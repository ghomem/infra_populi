# Paths created by a module class or the package it installs (HQ 2026-11-11 ruling 4, pregate dynamic probe).
# A needed path under <prefix> counts as provided when a class of the required_base closure declares <provider>
# (include / class { } / contain) or the plan lists it in required_external, or — provider `package:<name>` — a class
# of the closure installs that package (`package { '<name>': }`). Advisor-maintained; each line names its evidence.
# Format: <absolute path prefix> <provider class | package:<name>> — <evidence>
/etc/nginx nginx — puppet-nginx 8.4.0 class nginx installs the nginx package (Ubuntu: /etc/nginx/conf.d, sites-enabled)
/usr/bin/dconf package:dconf-cli — Ubuntu's dconf-cli package ships /usr/bin/dconf (gnome_lock_screen installs it and its exec requires Package['dconf-cli']; batch 4)
/etc/postfix package:postfix — Ubuntu's postfix package creates /etc/postfix (postfix_smtp_node installs it; its files subscribe to Package['postfix']; batch 4)
/etc/openvpn openvpn — puppet-openvpn 12.0.0 install.pp declares ${etc_directory}/openvpn and .../openvpn/keys (openvpn_server declares class openvpn; batch 4)
/usr/lib/x86_64-linux-gnu/openvpn openvpn — puppet-openvpn installs the openvpn package, which ships plugins/openvpn-plugin-auth-pam.so (Ubuntu multiarch path; batch 4)
/etc/mysql mysql::server — puppetlabs-mysql 17.3.0 mysql::server::install installs Package['mysql-server'] (mysql_server passes package_name mysql-server-<version>); Ubuntu's mysql-server/mysql-common create /etc/mysql and /etc/mysql/mysql.conf.d, and mysql_server's files there require Package['mysql-server'] (batch 5)
