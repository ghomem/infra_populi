## Local change #13 (puppet_boot_run)
- **Finding:** the boot script waits for apt/dpkg locks with `if ! lsof <three lock files>`.
  - Given several files, lsof exits 0 only when every one of them is open.
  - A real `apt-get update` holds only /var/lib/apt/lists/lock (measured on the node; the script's lsof returned 1).
  - So the wait ended at once.
- **Before:** results/puppet_boot_run/20261120T123031Z-author. The agent run started at 12:31:30, while the lock was
  held until 12:31:41. The reviewer reproduced it.
- **Change:** `[ -z "$(lsof -t <files>)" ]`, plus a one-line comment. One clear minimal design, so it went through
  policy B without an escalation.
- **After (20261120T124533Z):**
  - the agent run waited for a 15 s lock;
  - with a 150 s lock, it continued at the 120 s bound;
  - Phase 1 PASS 20261120T125244Z, Phase 3 PASS 20261120T125828Z.
