## For HQ
1. **nginx_base, a second puppet-nginx 8 incompatibility** (escalations/nginx_base.md, second section).
   - With `stream => true`, puppet-nginx 8.4.0 renders `access_log /var/log/nginx/stream-access.log;` with no format,
     and nginx refuses it (`log format is not specified`). The latest release is unchanged.
   - Production's 0.15 rendered no stream access_log.
   - **Recommendation:** `stream_access_log => 'off'` in nginx_base's default configs, which reproduces production.
   - nginx_frontend_mail is blocked on it.
