## Findings (all escalated, none holds the run)
1. **network_dhcp** (escalations/network_dhcp.behaviour.md):
   - Ubuntu 24.04 is netplan-only. The class installs ifupdown-extra, which does not pull in ifupdown, and writes an
     ifupdown stanza that nothing reads.
   - The boot step is missing, and p8test0 gets no address from the DHCP server beside it (which does serve
     `dhcpcd` by hand).
   - Options: A install ifupdown, B a netplan file, C a networkd file, D no fix. Recommended: decide together with
     network_static.
2. **openvpn_server** (escalations/openvpn_server.behaviour.md), OpenVPN 2.6.19:
   - **The class's cipher:** a client that offers only AES-256-CBC (the class's default, :19, :177) is refused ("no
     shared cipher") after its password succeeds. The server ignores `--cipher` for negotiation.
   - **Compression:** the server receives LZO but sends uncompressed (1237 against 139 bytes per packet for
     zero-filled pings). This is 2.6's default, against compression attacks.
   - Options:
     - cipher: A add it to data-ciphers, B data-ciphers-fallback, C both, D no fix;
     - compression: E allow-compression yes, F accept receive-only, G change the default.
   - Recommended: A and F.
3. **network_vpn** (escalations/network_vpn.behaviour.md): the same cipher finding, on its own default
   `openvpn_cipher` (:25, :57). Fixed with openvpn_server's option A.
