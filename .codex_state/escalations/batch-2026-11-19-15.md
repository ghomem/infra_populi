## Local change #8: my error on the way
- **The error:** the first value, `ChannelTimeout session=`, matched no channel type on OpenSSH 9.6. The node's
  sshd_config(5) lists session:command, session:shell and session:subsystem:..., with the example `session:*=5m`.
  Phase 3's check reported still-connected at once.
- **The fix, measured on the node:** with `session:*=10s`, an idle command session ended after 11 s and an idle
  interactive shell after 10 s, while a session printing every 5 s ran its full 21 s.
- **The review gap:** the first Phase 1 review (20261119T164240Z) passed the wrong value. It judged the diff against row
  #8, which carried the same value.
- **Why I don't count it as a false PASS:** no behaviour check passed something broken. The Phase 3 check is the
  behaviour gate, and it failed as it should. I report it plainly so HQ can judge it otherwise.
- **The lab fixture:** the real timeout also closed the lab's own silent SSH session to the node (exit 255), so the
  fixture moved from 10 to 30 s. The idle check now runs its test session detached on the node.
